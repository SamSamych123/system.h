# System.h — кроссплатформенная C-библиотека для системных вызовов

**System.h** предоставляет простой и единообразный интерфейс для определения архитектуры, операционной системы, компилятора, задержек, очистки экрана, ввода/проверки имени и пароля, а также выполнения команд. Библиотека написана на чистом C и совместима с C++.

## Лицензия
LGPL v2.1. Подробности в файле LICENSE.

## Возможности
- Определение архитектуры (x86_64, i386, ARM, ARM64, RISC-V 32/64/128)
- Определение типа ОС (Windows, Unix, FreeBSD, ToyOS)
- Определение конкретной ОС (Windows, Linux, Apple, Android, UNIX, FreeBSD, ToyOS)
- Определение компилятора (GCC, Clang, MSVC)
- Задержка в секундах (поддержка Windows, Unix и fallback)
- Посимвольная печать с задержкой
- Выполнение системных команд
- Универсальное логирование с уровнями (ошибки, предупреждения, информация, команды)
- Очистка экрана (cls / clear / ANSI)
- Запрос подтверждения с настраиваемым значением по умолчанию (Y/n или y/N)
- Ввод и проверка имени (макс. 30 символов)
- Ввод и проверка пароля (макс. 100 символов)

## Установка и сборка
Скопируйте `system.c` и `system.h` в ваш проект. Скомпилируйте вместе с основным кодом:
```bash
gcc -c system.c -o system.o
gcc main.c system.o -o myapp
```

Или включите `system.c` непосредственно в сборку.

## Пример использования

```
#include "system.h"
#include <stdio.h>

int main() {
    printf("Архитектура: %d\n", arch());
    printf("Тип ОС: %d\n", type_os());
    printf("ОС: %d\n", os());
    printf("Компилятор: %d\n", comp());

    if (conf_user("Продолжить?", 0)) {
        char name[31];
        name_user(name);
        printf("Привет, %s!\n", name);
    }

    clear_screen();
    print_with_delay("Привет, мир!\n", 0.1);
    return 0;
}
```

## Портирование

Библиотека тестировалась на Linux (GCC, Clang) и должна работать на Windows (MinGW, MSVC), macOS, FreeBSD, Android. Для добавления поддержки вашей ОС используйте макросы в начале `system.c` и `system.h`.
